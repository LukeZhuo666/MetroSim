# CityScope｜双城产业决策沙盘

**在同一个决策检查点改变一个条件，观察多方行动如何推动城市方案走向不同结果。**

CityScope 是面向城市产业选址议题的交互式决策推演系统。项目以成都与重庆争取机器人研发和制造项目为背景，将城市部门、企业、资本及社会主体放入同一沙盘，在资源、权限、信息和承诺等规则约束下推进决策。

## 推演问题

当同一个重大项目面对不同城市方案时，单项政策变化会如何影响企业选择、城市协商和最终落地结果？CityScope 关注的是行动链条及其后果，而不是预设一个固定结局。

## 推演机制

1. **建立方案**：组合土地、厂房、能源、人才住房、财政支持等可用资源。
2. **推进行动**：不同主体依据自身职责、信息和约束提出建议、签发方案、审计或回应。
3. **记录因果**：每次正式行动都会更新世界状态，并在时间线上留下可追溯的事件。
4. **比较干预**：从同一个检查点只调整一个允许变量，对照基线与干预后的续演过程。
5. **评估结果**：在推演结束后比较投资、就业、订单转化、产能利用、财政与社会影响。

## 系统特点

- 多主体在各自权限边界内独立行动，规则服务负责校验资源和约束。
- 不同终局由实际行动过程形成，结果不会由一个预设参数直接指定。
- 方案生成和排序纳入推演过程，关键决策可追溯到对应方案。
- 3D 双城沙盘、因果时间线与单变量干预共同呈现“为什么出现这个结果”。

## 项目信息

- **方向**：多主体决策支持与因果推演
- **场景**：西部研发总部与智能制造基地的双城选址
- **体验关键词**：多 Agent、资源约束、行动链、因果追踪、情景对照
