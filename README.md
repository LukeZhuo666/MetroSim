# 城策局（MetroSim）

城策局是一款双城产业选址推演工具。调整成都方案中的土地、人才、能源和政策承诺，运行本地评分模型，观察企业倾向与城市指标如何变化。

## 开始使用

打开 [城策局](https://lukezhuo666.github.io/MetroSim/)，调整四项资源滑块，点击“运行本轮推演”。保存情景后改变某一项变量，再运行并比较结果；也可以载入之前保存的方案。

## 功能

- 实时更新成都与重庆的综合指数和分项指标
- 记录每轮行动及模型反馈
- 保存、载入多组情景方案
- 一键重置初始条件
- 浏览器本地运行并保存，不需要账号

综合指数是用于体验变量关系的演示模型，不代表真实城市评估或投资建议。
