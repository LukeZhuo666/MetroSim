# CityScope

> 改变一个原因，观察双城决策如何走向不同结果。

**LukeZ 过往作品独立展示。** 这里是为报名准备的案例介绍，不包含原项目源码或素材；项目详情、协作者与贡献记录以[原项目仓库](https://github.com/eiddiedev/CityScope)为准。

## 项目概览

CityScope 是双城竞合因果沙盘，以多主体行动、约束门与因果时间线呈现复杂决策。

## 展示重点

- 成都、重庆与企业等主体在权限、资源和承诺约束下续演。
- 交互沙盘让用户调整一个允许变量，比较基线与干预结果。
- 终局后计算投资、就业、产能、补贴等影响，展示多种决策走向。

## 技术与体验关键词

Multi-Agent · Causal Simulation · 3D Sandbox
